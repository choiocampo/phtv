# phtv

A small repository for a Philippine TV channel playlist file.

## Overview

This repository contains an M3U playlist for Philippine TV channels. The playlist can be opened in compatible media players and IPTV applications.

## Files

- `phchannels.m3u` — a channel playlist in M3U format.

## Usage

1. Open the `phchannels.m3u` file in a media player that supports IPTV playlists, such as VLC, Kodi, or IPTV Smarters.
2. Alternatively, use a dedicated IPTV app that accepts local M3U playlist files.

## Notes

- The playlist may contain live stream URLs for Philippine channels.
- Stream availability depends on the source and network conditions.
